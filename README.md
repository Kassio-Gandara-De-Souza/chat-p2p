# Chat P2P em Python

Aplicação de chat ponto a ponto (P2P) em Python, em que os participantes se comunicam diretamente, sem um servidor central.

> **Trabalho em grupo** (grupo 9) de disciplina na UnB (2025).
> Repositório do grupo: [Pedro-Augusto-Cardoso/pyp2p-grupo-9](https://github.com/Pedro-Augusto-Cardoso/pyp2p-grupo-9). Este repositório resume o projeto e a **minha parte**.

## O que eu fiz

- Desenvolvi a **interface de linha de comando (CLI)** do chat, por onde o usuário se conecta aos outros participantes e troca mensagens.

## Tecnologias

Python · sockets · redes P2P · Sphinx (documentação)
